# evidence/ — log bằng chứng thô cho spec.md §1

Rubric R1 (6 điểm) yêu cầu log đầy đủ, kiểm lại được. Chọn chuẩn A và/hoặc B:

**Chuẩn A — khảo sát**
- ≥20 người ngoài nhóm, ≥50% xác nhận pain
- Log đủ: danh sách câu hỏi + **từng câu trả lời nguyên văn** (không tóm tắt)
- Đặt tại: `survey-questions.md`, `survey-responses.md`

**Chuẩn B — mining**
- Số đếm được + ≥5 ví dụ nguyên văn có nguồn
- **Phương pháp đếm phải kiểm lại được**: đếm trên tập nào, tiêu chí gán nhãn, ai gán, script nếu có
- Đặt tại: `mining-method.md`, `mining-results.md`, script trong `scripts/`

Nguồn dữ liệu thật: `../../data/` (chatlog VLearn tutor + transcript bài giảng).
Lưu ý quy định bảo mật dữ liệu được cấp — xem `../../01-de-bai.md`.
